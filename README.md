# ajgoramarkaj.github.io
আজগড়া মারকাজ মাসজিদ | দ্বীনি ভাইদের যোগাযোগ ও দাওয়া'হ গ্রুপ  ✎ᝰ আজগড়া মারকাজ মাসজিদ (Ajgora Markaj Jame Masjid), আজগড়া, বেলকুচি, সিরাজগঞ্জ। এখানে ইনশাআল্লাহ মারকাজের গুরুত্বপূর্ণ কার্যক্রম, বৃহস্পতিবারের আমন্ত্রণ ও রিমাইন্ডার, দ্বীনি আলোচনা, নসীহত এবং প্রয়োজনীয় তথ্য শেয়ার করা হবে।
